# triboanalisi
Triboanalisi is a software dedicated to the processing of raw, noisy analytical outputs from sensors (e.g. strain-gages, torque-meters, thermocouples)

## Aim and scope

In academic and industrial research, it's common to handle raw data from sensors such as load cells, torque transducers, or thermocouples. 
This script represents a modest attempt to harmonize noisy data by grouping them and calculating their means and standard deviations.

## How to use
To run the script, you must have Python 3 installed. 
Moreover, the following libraries are required:
- pandas
- numpy
- matplotlib

To install them, simply use the following command from your terminal:

```bash
pip install pandas numpy matplotlib
```
